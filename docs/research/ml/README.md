# Responsible-ML evidence

## Decision

The learned residual ranker was not promoted. The deterministic system retained production ranking authority.

## Frozen result

- 95 fresh final pairs
- 51.58% learned pairwise accuracy versus 50.53% deterministic
- +1.05 percentage points, below the predeclared +3-point gate
- grouped 95% improvement interval: −4.21 to +6.32 points
- 26.32% learned top-choice accuracy versus 31.58% deterministic
- five promotion gates failed
- zero hard-eligibility and skincare-safety violations
- exact Python/plain-JavaScript order and tie parity

The raw labels, retailer-derived snapshots, and trained artifact are excluded from this showcase. The aggregate decision is documented without exposing uncleared source material.
