# Reproducible synthetic learning-to-rank

**Offline engineering example, not a better skincare recommender.** This independent example trains a small pairwise logistic model from zero, exports it, and executes the same bounded inference in Python and native browser JavaScript. It does not import private data, change the application, or enable its trained private model.

## Reproduce

From the public repository root, using Python 3.9+:

```bash
python3 examples/ml_ranking/pipeline.py verify
python3 -m unittest discover -s examples/ml_ranking -p 'test_pipeline.py' -v
python3 examples/ml_ranking/pipeline.py report
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [the local browser example](http://127.0.0.1:8000/examples/ml_ranking/browser.html). Expected: **PASS — 50 Python / JavaScript cases**, numeric error at most `1e-9`, six rejected invalid models, and rejected modified model bytes. The page displays one fictional teacher-versus-learned comparison. Stop the server with `Ctrl-C`.

For automated real-browser parity and 1440px/390px layout checks, with an existing Chrome or Chromium installation:

```bash
python3 -m unittest discover -s examples/ml_ranking -p 'test_browser.py' -v
```

This uses an ephemeral loopback server, exact-width browser frames, and a temporary isolated browser profile; external DNS is blocked. No Node, npm, Python packages, credentials, external service, or model-provider call is needed. Chrome itself is not installed by this example. If absent, browser verification fails explicitly rather than silently skipping. The Python-only test command remains usable.

`verify` regenerates all seven files in memory and compares them byte-for-byte with [artifacts/manifest.json](artifacts/manifest.json). Expected: `PASS: 7 reproducible artifacts; synthetic baseline imitation only`. To regenerate missing artifacts, run `python3 examples/ml_ranking/pipeline.py build`; it refuses to overwrite different frozen files. This is deterministic reproduction of an already-opened study, not another untouched holdout evaluation.

## Data and label provenance

All examples are original, procedural fictional records generated by [pipeline.py](pipeline.py). No retailer record, private label, model weight, screenshot, user preference, or LLM output is copied. The five numeric features are synthetic `concern_match`, `ingredient_match`, `budget_fit`, `evidence_completeness`, and `active_fit`. Their toy generation rules are not clinical or product-scoring recommendations.

Labels are generated by an explicitly defined deterministic teacher with weights `[1.8, 1.2, 0.8, 0.4, 0.6]`. A pair is labeled according to the teacher's score difference; exact ties are excluded. Therefore **this is baseline imitation**. The teacher has 100% agreement with its own labels by construction; the learned model cannot establish an improvement over it. High agreement says nothing about consumer usefulness, safety, treatment outcomes, or real recommendation quality.

Seed `20260905` creates 24 independent family bundles. Each has two correlated query variants and five fictional product families. The split is assigned at bundle level before training: 16 training, four development, four final bundles. Both query families and product families are disjoint across splits. Products shared by correlated variants never cross a split. The resulting 48 queries produce 320 training, 79 development, and 80 final non-tied pairs; these pairs are correlated observations, not 479 independent people or independent judgments.

## Frozen experiment and results

[design.json](artifacts/design.json) records version `synthetic-ranking-imitation-v1`, feature order, seed, labeling rule, split sizes, metrics, and optimizer configuration. One fixed configuration is trained on the training split only: zero initialization, full-batch pairwise logistic gradient descent, 300 epochs, learning rate 0.35, L2 coefficient 0.02, no intercept, no fitted feature normalization. Features already lie in `[0,1]`. Learned weights are exported at 12 decimal places, not copied from the teacher.

Development results are diagnostic: there is no hyperparameter search, best-checkpoint selection, or early stopping. Model construction precedes report construction. Final data does not enter training or model selection. This study's final results have now been opened; changes motivated by those results require a new version and fresh family groups. Regression tests pin the design and model hashes. Repeated `verify` calls confirm the same frozen output, not new evidence.

| Split | Queries / non-tied pairs | Learned pairwise teacher agreement | Learned top-choice agreement |
|---|---|---|---|
| Training | 32 / 320 | 311/320 (97.19%) | 32/32 (100%) |
| Development | 8 / 79 | 75/79 (94.94%) | 8/8 (100%) |
| Final | 8 / 80 | 76/80 (95%) | 6/8 (75%) |

The teacher baseline is 100% for both metrics in every split. [report.json](artifacts/report.json) retains exact counts. Metrics assess the raw learned score ordering, **before** the demonstration-only displacement cap; they are not bounded-panel quality scores. No significance, medical quality, production uplift, latency, cost, adoption, or human-evaluation claim is made.

## Artifact and runtime boundary

- [model.json](artifacts/model.json) contains learned coefficients and hashes of the design, dataset, and frozen split.
- [inference.js](inference.js) independently validates version, feature order, finite weights, training-hash shape, and a strictly non-authoritative policy.
- [browser.js](browser.js) verifies model/parity bytes against the checked-in manifest before evaluation. Checksums detect drift relative to that manifest, **not authenticity against an attacker who replaces both**; review the repository/source commit to establish provenance.
- Only five uniquely identified fictional candidates with finite `[0,1]` features and exact scope `fictional-comparison` are supported. Unsupported, malformed, non-finite, duplicate, or invalid-model input falls back without learned control.
- The comparison cannot move a candidate more than two positions. Exact ties retain input order. It returns a comparison value; it never mutates input or application state, persists preferences, fetches a provider, or asserts production ranking authority.
- Browser content uses `textContent`, not HTML interpolation. A same-origin content policy blocks external resources. Ordinary browser mode only reads local artifacts; the automated test mode sends its small test result to its own temporary loopback server.

All file hashes are recorded in [the manifest](artifacts/manifest.json). Runtime is standard-library Python 3.9+ and browser ES modules/Web Crypto; there are no dependency versions to install. Byte-identical Python reproduction and browser numeric tolerance are tested independently. The manifest is an integrity inventory, not a cryptographic signature.

## Code tour and failure tests

1. `generate` / `validate_split` → procedural fixtures and correlated-family isolation.
2. `pairs` / `train` → teacher labels and actual logistic optimization on training only.
3. `build` / `metrics` → frozen model export before development/final reporting.
4. `validate_artifact` / `infer`, mirrored in JavaScript → strict inputs, non-authority policy, bounded order, fallback.
5. [test_pipeline.py](test_pipeline.py) → reproducible bytes, family leakage, held-out exclusion, invalid models/features, tie stability, no mutation, CLI operation.
6. [test_browser.py](test_browser.py) → actual Chrome/Chromium execution, 50 cross-runtime cases, checksum rejection, invalid-model rejection, and exact 390/1440px layout.

## Separate from the existing private study and live demo

The historical private residual study evaluated **95 owner-reviewed pairs**, not these synthetic labels: 51.58% learned versus 50.53% deterministic accuracy, +1.05 percentage points, grouped 95% interval −4.21 to +6.32 points. Five promotion gates failed. Its evidence and decision remain unchanged; see the [responsible-ML case study](../../docs/portfolio/responsible-ml.md).

The existing [live ML comparison](https://skincarehub.app/catalog/?mlDemo=1) is a separate, opt-in artifact. It compares only the already-eligible deterministic top five, limits movement to two positions, falls back for unsupported/safety-sensitive contexts or invalid artifacts, and has a **Disable ML demo** control. Deterministic product cards remain authoritative. That private-model demonstration is not reproduced by this synthetic example, and the public application still does not enable the private trained model.
